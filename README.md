# 가나 공부 (히라가나 · 가타카나)

일본어 글자를 익히는 안드로이드 앱입니다.

## 📥 내려받기

휴대폰으로 아래 링크를 눌러 APK를 받아 설치하세요.

**[최신 버전 내려받기 페이지](https://github.com/g59raphy/kana-study/releases/latest)** — 페이지에서 `kana-study-v버전.apk` 파일을 누르세요.

1. 페이지 아래 Assets 에서 `kana-study-v1.0.○.apk` 를 눌러 내려받습니다.
2. 내려받은 파일을 엽니다.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켭니다.
4. **설치**를 누릅니다.

새 버전이 나오면 같은 방법으로 받아 설치하면 학습 기록이 그대로 유지된 채 업데이트됩니다.

> 아이폰은 앱 스토어 밖에서 앱을 설치할 수 없어 지원하지 않습니다.

## ✨ 기능

- **오십음도** — 기본 46자 + 탁음·반탁음 25자. 글자를 누르면 일본어 발음을 들려주고, 한글·로마자 발음과 반대쪽 글자(히라가나↔가타카나)를 보여줍니다.
- **퀴즈** — "글자 → 발음", "발음 → 글자" 4지선다. 자주 틀리는 글자가 더 자주 나옵니다.
- **쓰기 연습**
  - *따라쓰기*: 회색 글자 위에 손가락으로 따라 씁니다.
  - *보고쓰기*: 발음만 보고 글자를 떠올려 씁니다.
  - **채점**을 누르면 모범 글자와 겹쳐 보여주고 점수를 매깁니다.
- 학습 기록(맞힌 횟수, 쓰기 최고 점수)은 휴대폰에 저장되고 오십음도에 색 점으로 표시됩니다.

## 🛠 개발

- 앱 화면: `www/index.html` (HTML/JS 한 파일, 컴퓨터 브라우저로 열어 바로 확인 가능)
- 안드로이드 포장: [Capacitor](https://capacitorjs.com/)
- `main` 브랜치에 올리면 GitHub Actions가 APK를 만들어 Releases에 자동으로 올립니다.
- 서명 키는 저장소의 Secrets(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`)에 있습니다.
